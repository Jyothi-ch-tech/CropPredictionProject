# 🌱 Crop Recommendation System

An intelligent Machine Learning-based system that recommends the most suitable crop based on environmental and soil conditions.

---

## 🚀 Features

* Predicts best crop using ML algorithms
* Achieves **85–90% accuracy**
* Handles real-time user input
* Interactive UI built with Streamlit

---

## 🧠 Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Streamlit

---

## 📊 Dataset

* Contains 1000+ samples
* Features include:

  * Nitrogen, Phosphorus, Potassium
  * Temperature, Humidity, pH, Rainfall

---

## ⚙️ How It Works

1. Data preprocessing & cleaning
2. Feature engineering
3. Model training (classification algorithms)
4. Prediction via user input

---

## ▶️ Run Locally

```bash
git clone https://github.com/Jyothi-ch-tech/CropPredictionProject
cd CropPredictionProject
pip install -r requirements.txt
streamlit run app.py
```
